# typamud MVP+

`typamud` — это локальный telnet-MUD на Python + asyncio с русским интерфейсом и курсом на более узнаваемую RU-MUD модель: выбор расы и класса при создании персонажа, тиковая боевка, активные умения, экипировка, магазины, банк, гостиница и локальная SQLite-персистентность.

## Запуск

```bash
python -m typamud.main
```

Подключение из другого терминала:

```bash
telnet 127.0.0.1 4000
```

## Что уже есть

- asyncio telnet-сервер;
- вход по имени персонажа и создание нового героя через выбор расы/класса;
- стартовый город **Лонгред** целиком описан в `data/world.json` как набор явных комнат без автогенерации гильдий или скрытых достроек в loader-е;
- внутри Лонгреда уже подключены отдельные подзоны: **библиотека**, **парк**, **канализация**, **таверна**;
- библиотека оформлена отдельной боевой зоной: около 10 мобов (задумчивый читатель `10`, любопытная читательница `12`, серьезный читатель `13`) и босс `15` уровня — главный библиотекарь;
- парк уже заселен стартовыми мобами уровней `1-5`, а в яме парка живет агрессивный босс `7` уровня — бешеный пес;
- канализация получила отдельную боевую ветку: слизни `5` уровня, агрессивные бешенные крысы `6` уровня, жирные крысы `8` уровня и босс `10` уровня — крысиный король, который бьет `4` раза за тик боя;
- расы: лесные эльфы, высшие эльфы, полуэльфы, горные дварфы, глубинные дварфы, человек, орк, гоблин, великан, полуорк;
- классы сгруппированы так: **воины без магии** — берсерк, воин щита, авангард, защитник; **воины с магией** — паладин, черный рыцарь; **священники** — инквизитор, лекарь, шаман; **маги** — варлок, маг огня, маг воды, маг земли, маг воздуха; **разведчики** — разбойник, ассасин;
- активные умения по классам: `bash`, `rage`, `fortify`, `smite`, `heal`, `holywrath`, `darkbolt`, `souldrain`, `blindness`, `curse`, `exorcism`, `fireburst`, `fireball`, `greaterheal`, `iceshard`, `icestrike`, `tidalwave`, `stonefist`, `stoneskin`, `earthshatter`, `airburst`, `lightning`, `restoreenergy`, `spiritlink`, `shadowflame`, `backstab`, `trip`, `bless`;
- у каждого умения есть процент владения от `10%` до `100%`, и успех применения зависит от этого значения;
- у каждого класса есть **своя статичная гильдия в Лонгреде**, а все переходы между кварталами идут только через `north/south/east/west/up/down`;
- часть продвинутых заклинаний требует учебную книгу; новые книги второго круга для лекаря, шамана и стихийных магов может выбросить бешеный пес в парке;
- крысиный король дропает книги `3` круга для всех кастеров и по одному оружию на каждый тип: **клинки**, **топоры**, **булавы и молоты**, **короткие клинки**, **копья и шесты**;
- главный библиотекарь дропает книги `4` круга для всех кастеров;
- мир с лавками оружия, брони, дорожных товаров, магии, банком, рубиновой лавкой и гостиницей;
- тиковая боевка, автоатака, бегство, регенерация и отдых;
- PvP отключен: нельзя атаковать или кастовать умения по другим игрокам;
- инвентарь, экипировка, предметы на земле и лут с мобов;
- опыт, уровни, золото, банк и рубины;
- SQLite-сохранение персонажа вместе с инвентарем и экипировкой.

## Следующие шаги для большего сходства с классическими RU-MUD

- вручную нарастить количество воинских скиллов и магических школ до целевых объемов;
- отдельные зоны подключать поверх Лонгреда как самостоятельные пакеты world-data;
- городские NPC-торговцы и формат диалогов вместо абстрактных сервисов комнаты;
- zone reset / respawn timer / world-builder команды;
- группы, каналы, социалы, кланы и более сложная экономика.

## Публикация проекта на GitHub

Если репозиторий уже инициализирован локально, достаточно привязать удаленный origin и выполнить push:

```bash
git remote add origin https://github.com/<username>/<repo>.git
git branch -M main
git push -u origin main
```

Если `origin` уже существует, обновите URL и повторите push:

```bash
git remote set-url origin https://github.com/<username>/<repo>.git
git push -u origin main
```

## Перенос проекта на Windows в `C:\GitHub\Edm`

Чтобы получить эту игру на компьютере Windows именно в папке `C:\GitHub\Edm`, выполните команды в PowerShell:

```powershell
mkdir C:\GitHub -Force
cd C:\GitHub
git clone https://github.com/<username>/<repo>.git Edm
cd C:\GitHub\Edm
```

Если репозиторий уже есть на диске и нужно просто обновить локальную копию:

```powershell
cd C:\GitHub\Edm
git pull
```

Запуск игры после переноса:

```powershell
cd C:\GitHub\Edm
python -m typamud.main
```
